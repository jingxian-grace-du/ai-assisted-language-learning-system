# Learning philosophy

## English as part of life

The system treats language and AI as tools. English is not practised only to perform English exercises; it is used to recount experience, clarify questions, examine choices, and develop ideas. AI is not only a correction engine; it can help the learner find language, see alternative perspectives, and organise thought.

The desired change is gradual:

```text
English as studied knowledge
→ English as a recurring activity
→ English as a thinking and communication tool
→ useful expressions retained in long-term memory
```

## Long-term compounding

This approach does not target urgent examination needs or rapid visible gains. It depends on consistent use, accumulated personal relevance, repeated retrieval, and feedback across many cycles. The expected benefit is durable because the learner repeatedly connects language with lived meaning and later retrieves it through spaced practice.

## Habit through intrinsic value

A habit is more likely to persist when the activity produces a meaningful reward. An oral diary can provide that reward when it helps the learner:

- make sense of the day;
- articulate something previously vague;
- notice a pattern or assumption;
- receive a useful alternative perspective;
- move from confusion toward an actionable understanding.

The goal is not forced daily compliance. It is a positive reasoning chain in which the learner returns because the conversation is useful.

## Describe before translating

When the learner cannot recall a word, the preferred response is to describe the concept using available English and ask the AI to identify a suitable expression. This reduces dependence on word-for-word translation and strengthens relationships inside the learner's English meaning network.

Translation remains a legitimate support and memory-design tool. The principle is not a ban on the learner's first language; it is a preference for attempting English-mediated meaning before defaulting to direct lexical substitution.

## Messiness is valid input

Early oral diaries may be repetitive, loosely structured, or limited to a chronological account of the day. That is not a failure. Learning to recognise topics, separate observation from interpretation, and express causal or reflective connections is itself part of the system.

The processing pipeline must therefore accept unstructured material without pretending that every conversational turn is already a clean topic or a useful card.

## Personal relevance without public exposure

Personal relevance is central to the learner's private process, but private content is not required to explain, publish, or develop the system. The public project works with abstract contracts and synthetic tests. Real learning content remains local and under the learner's control.
