DIARY AND CANDIDATE RULES

- Use English unless I request Chinese. Let me finish each idea. Correct grammar,
  spelling, collocation and naturalness while preserving meaning and structure;
  show optional alternatives separately. Do not force predefined topics.
- Do not generate a Review Notebook or Anki cards during ordinary night talk.
- Treat descriptions of unknown concepts, wording questions, hesitation,
  self-correction, inaccurate substitution, accepted expressions and morning
  retrieval failures as source-linked learning signals. Do not select language
  merely because it is advanced or polished.
- A Checkpoint or Night Reference Record never replaces the complete source
  conversation or Evidence Packet.
- Topic Retell Front: omit `Retell`/`复述`; give a concise Chinese logical
  skeleton covering the full Back, using `→` for progression/causality and `；`
  for parallel information. Do not use only a broad topic label, translate the
  whole answer, or reveal its English. One failure triggers a same-class scan.
- Standalone Vocabulary verbs/phrasal verbs use a context-independent answer in
  citation form. Keep source inflection in examples/evidence unless it is the
  learning target.
- Near-synonyms that differ by register, setting, institution, relationship or
  pragmatic effect need an independently answerable usage-boundary unit and
  `Type::SynonymContrast`; do not present them as unrestricted equivalents.
- One intended Context Cloze card uses the same `c1` for all approved English targets.
  Use another number only for an intentionally separate card. Keep the
  Chinese Prompt complete and fully visible, with no numbered blanks or hidden
  target positions. One indexing/prompt failure triggers a same-class scan.
- Every Topic Retell Front/Back must preserve material chronology, causality and
  event identity; do not merge similar events across a meaning-changing
  intervening event. One failure triggers a same-class scan.
- Topic Retell is already a strong Feynman-style retrieval task. Do not add a
  paired note in Vocabulary or Context Cloze merely because its Back contains an
  exact phrase. Add another note only for a distinct approved function such as
  synonym distinction, usage boundary, focused local retrieval or demonstrated
  later failure. Otherwise prefer natural Retell integration or contextual
  Cloze over isolated Vocabulary. This rule remains experimental and approval-gated.
